# SuperDictate 0.2.48

## Обновление

В панели приложения нажмите «Проверить», затем «Обновить».
Подпись приложения не меняется, разрешения не сбрасываются, существующие модели
сохраняются. Обновление устанавливается только по вашему действию.

После обновления с 0.2.47 панель один раз скачает готовые компоненты распознавания
с GitHub (около 280 МБ), покажет прогресс и распакует их. Не нужно устанавливать
Python, Homebrew, Xcode или пакеты. При сетевой ошибке доступны повтор и логи.
Это отдельный архив, поскольку старый обновлятор ограничивает размер приложения
64 МиБ. Последующие запуски используют готовые компоненты без повторной загрузки.

Новая установка:

```bash
curl -fsSL https://raw.githubusercontent.com/shlgd/SuperDictate/v0.2.48/install.sh | /usr/bin/arch -arm64 /bin/bash
```

Полный установщик уже содержит компоненты. Веса дополнительных моделей
по-прежнему скачиваются по выбору из настроек. Parakeet остаётся по умолчанию.

## Исправления

- Готовый Python и библиотеки вместо установки зависимостей на машине пользователя.
- Немедленный статус кнопки загрузки, этапы, байты, скорость, отмена и повтор.
- Ограниченное ожидание списка файлов модели и понятные ошибки сети/диска.
- Кнопка экспорта обезличенных логов. Нет аудио, текста диктовок, буфера обмена,
  личных путей, токенов или идентификаторов устройства.
- Восстановление разрешений в основной панели с перезапуском проверки статуса.

## Проверено

Готовый архив: импорты после переноса, распаковка без сети, повторное использование,
сохранность весов, очистка прерванной подготовки, отказ при повреждении.
Чистая загрузка Whisper Turbo: 1 613 977 880 байт за 89,2 секунды на тестовой сети,
без установки пакетов и инструментов разработчика. Скорость у других пользователей
зависит от сети. Проверен рабочий helper обновления на настоящих архивах
0.2.47 и 0.2.48, без запуска тестовых копий приложения; подпись сохранена.

Нужны Apple Silicon, macOS 14+ и свободное место. Компоненты занимают около 1,1 ГБ
после распаковки, отдельно от весов. Старое окружение сохранено для отката.
Недоступность GitHub/Hugging Face/CDN или нехватка места всё ещё могут помешать
загрузке. Испытания на этой машине не гарантируют работу в любой сети.

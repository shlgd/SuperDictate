# SuperDictate 0.2.46

## Новое

- Выбор локальной модели в настройках: Parakeet, Whisper Large-v3,
  Whisper Large-v3 Turbo, Qwen3-ASR 0.6B/1.7B и GigaAM v3.
- Загрузка дополнительных моделей с прогрессом, отменой и удалением.
  Пока идёт загрузка, можно диктовать текущей моделью.
- Изолированный Python и зависимости устанавливаются автоматически;
  системный Python и Homebrew не нужны.

## Исправления

- Только один фоновый агент может владеть блокировкой запуска.
- Повторный keyDown без отпускания клавиши не останавливает запись.
- Открытие истории не сбрасывает ожидающий запуска режим диктовки.
- После ошибки старта микрофона следующая попытка запуска не пропускается.

## Обновление и ограничения

Обновиться можно через проверку обновлений в панели управления.
Постоянная подпись из 0.2.45 сохранена. При переходе со старых ad-hoc сборок
может понадобиться однократно выдать разрешения заново.

Parakeet остаётся выбранным по умолчанию. Его уже установленная модель не
скачивается повторно, если кеш проходит проверку. Дополнительные веса
скачиваются только по запросу из настроек, требуют интернета и свободного
места. Для них пока нет зеркала в GitHub Releases.

Проверены все debug-самотесты, протокол обмена с локальным движком,
автоматическое окружение, девять Python-тестов и шесть распознаваний Qwen 0.6B.
Release-сборка подписана прежним сертификатом; проверены совместимость подписи
с 0.2.45 и установка/повторная установка без запуска тестовых копий приложения.
Качество всех пяти дополнительных моделей на реальной речи и совместимость
со всеми поддерживаемыми Mac не подтверждены. Ограничения и размеры:
[локальные модели](../local-models.md).

# SuperDictate 0.2.45

- Постоянная подпись публичных сборок: следующие обновления используют тот же сертификат и идентичность приложения.
- Проверка совместимости подписи перед заменой приложения. При несовместимой подписи установленная версия остаётся на месте.
- В диагностическом журнале запуска теперь указаны версия и номер сборки.
- История, настройки и загруженная модель при обновлении сохраняются. Модель повторно скачивать не нужно.

## Обновление

Откройте SuperDictate из Applications, нажмите «Проверить», затем «Обновить».
Приложение не устанавливает обновления самостоятельно в фоне.

При первом переходе со старой ad-hoc-подписи macOS может попросить заново выдать
разрешения. Это разовая смена идентичности, а не обещание отсутствия любых будущих
запросов macOS. Новая подпись не является Apple Developer ID и не отменяет
системные проверки первого запуска. Экспериментальные дополнительные модели
в этот релиз не включены.

Для новой установки или старой версии без кнопки обновления:

```bash
curl -fsSL https://raw.githubusercontent.com/shlgd/SuperDictate/v0.2.45/install.sh | /usr/bin/arch -arm64 /bin/bash
```

# SuperDictate 0.2.47

Исправление кнопки скачивания дополнительных моделей.

- Кнопка использует собственный идентификатор модели и больше не зависит
  от наличия временного черновика настроек. Исправлен сценарий, в котором
  нажатие молча игнорировалось после потери черновика.
- При уже запущенной загрузке повторное действие обновляет её статус.
- Прогресс обновляется только в текущей форме настроек, а не в старом представлении.
- Добавлены диагностические сообщения о нажатии, запуске, отмене и ошибке загрузки.
- Отменённая до запуска задача не начинает подготовку окружения.

Проверены выбор модели, доступность кнопки для клика и появление прогресса
с отменой, включая регрессионный случай Whisper Turbo без черновика настроек.
Этот случай воспроизведён тестом; причина исходной жалобы на другом Mac
пока не подтверждена. Исправление не гарантирует устранение сетевых ошибок.

Все модели и функции 0.2.46 сохранены. Обновление доступно через панель
управления приложения. Постоянная подпись сохранена; повторная загрузка
уже проверенной модели Parakeet не требуется.

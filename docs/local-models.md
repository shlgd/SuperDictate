# Локальные модели

Выбор дополнительных локальных моделей доступен начиная с v0.2.46.
Parakeet остаётся выбранным по умолчанию. Его установка, движок и кеш не меняются.

## Как попробовать

1. Откройте панель SuperDictate, затем настройки.
2. В верхнем разделе «Модель распознавания» выберите модель.
3. Нажмите «Скачать». Приложение само скачает изолированный Python и общий движок,
   затем выбранные веса. В настройках отображаются стадия, байты и прогресс;
   при загрузке весов также показывается скорость. Homebrew и ручная установка
   Python не нужны. Загрузку можно отменить.
4. Продолжайте диктовать старой моделью во время загрузки.
5. После загрузки завершите текущую диктовку и нажмите «Сохранить».
   Переключение временно приостанавливает службу, пока модель загружается в память.
6. Чтобы вернуться, выберите Parakeet и сохраните настройки.
7. Ненужную модель можно удалить кнопкой в этом же разделе. Активную модель
   сначала нужно переключить. Удаление последней дополнительной модели при
   активном Parakeet освобождает также общий движок и его Python.

| Вариант | Размер весов | Движок |
| --- | --- | --- |
| Whisper Large-v3 | 3,08 ГБ | MLX, GPU |
| Whisper Large-v3 Turbo | 1,61 ГБ | MLX, GPU |
| Qwen3-ASR 0.6B, 8-bit | 1,01 ГБ | MLX, GPU |
| Qwen3-ASR 1.7B, 8-bit | 2,47 ГБ | MLX, GPU |
| GigaAM v3 E2E RNNT | около 1 ГБ | PyTorch, CPU; русский язык |

Общий движок с Python занимает примерно 1,2 ГБ на диске и устанавливается один раз
для всех дополнительных моделей. Размеры весов не включают рабочую память. Нет
обещания, что эти модели быстрее или точнее Parakeet: пользователь сравнивает их
на собственной речи. Whisper v1/v2 и облачный SpeechKit не добавлены.

## Ограничения прототипа

- Python 3.11 поставляется автоматически из зафиксированного официального релиза
  Astral python-build-standalone с проверкой SHA-256. Системный Python не меняется.
- Установка Python-пакетов требует интернета и совместимой версии macOS;
  минимальная macOS для новых MLX-пакетов может быть выше, чем у базового приложения.
- Веса загружаются из зафиксированных ревизий Hugging Face, GigaAM из CDN Сбера.
  Эти экспериментальные веса пока не зеркалируются в GitHub Releases.
- Длительное аудио делится на отрезки до 24 секунд с поиском тихого места для
  разреза. На границах возможны ошибки слов и потеря контекста. Это особенно важно
  проверить на длинной диктовке. Внешний VAD и облачные API не используются.
- Первый запуск тяжелее последующих; модель остаётся в отдельном процессе.
  Принудительный предел одного запроса распознавания — 10 минут ожидания.
- При ошибке переключения приложение возвращается на прежнюю модель; при ошибке
  загрузки сохранённой экспериментальной модели при запуске — на Parakeet.
- Совместимость и качество всех пяти моделей на реальной речи ещё не проверены.
  Дополнительные модели следует сравнивать на своей речи; Parakeet остаётся
  стандартным вариантом. Выпуск функции не означает одинаково проверенное
  качество всех движков на всех поддерживаемых Mac.

Все экспериментальные файлы находятся в
`~/Library/Application Support/SuperDictate/LocalModels/`.
Подробности установки и ошибок: `installation.log` и `worker.log` в этой папке.
Логи обнуляются при новом запуске соответствующего процесса. Архив интерпретатора,
временные окружения и недокачанная новая модель удаляются после ошибки или отмены.
После аварийного завершения оставшиеся временные файлы очищаются при следующем
запуске дополнительной модели или операции загрузки. Установленный общий движок
остаётся для повторного использования; это не временный кеш.
Аудио передаётся локальному процессу временным файлом; после запроса файл удаляется.
Распознавание не использует сеть. Необязательная AI-чистка текста остаётся отдельной
настройкой со своим поведением.

## Проверки без загрузки моделей

Для проверки состояния кнопки и отказов загрузки (debug-сборка):

```bash
swift run --package-path swift Parakey --self-test local-model-ui
swift run --package-path swift Parakey --self-test local-model-lifecycle
swift run --package-path swift Parakey --self-test runtime-network
```

`runtime-network` запускает HTTP-сервер только на loopback: успешная передача,
HTTP 503, отсутствие ответа, обрыв тела, отмена и повторная попытка. Он также
проверяет тайм-аут и отмену процесса распаковки. Модели и разрешения не меняются.
UI-тесты проверяют AppKit-кнопку, статус, отмену, закрытие/повторное открытие формы
и обновление формы после завершения; это не тест реальной сети другого Mac.

Полная установка Whisper Turbo в пустую временную папку (несколько ГБ трафика):

```bash
python3 -B scripts/test-local-model-install.py --python "$HOME/Library/Application Support/SuperDictate/LocalModels/cpython-3.11.16-20260901/bin/python3"
```

Тест ограничен 600 секундами, проверяет файлы по манифесту и удаляет временный
каталог. Рабочие модели не меняются. 17 сентября 2026 чистая установка прошла
за 128,5 с, размер проверенных файлов модели: 1 613 977 880 байт. Это проверка
установки, а не качества распознавания. Скорость на другой сети не гарантируется.

В журнале приложения строки `local model download` содержат этап и счётчик времени.
Подробности установки зависимостей находятся отдельно в
`~/Library/Application Support/SuperDictate/LocalModels/installation.log`;
перед передачей такого файла следует удалить личные пути и возможные секреты.

```bash
swift run --package-path swift Parakey --self-test all
swift run --package-path swift Parakey --self-test local-model-protocol
swift run --package-path swift Parakey --self-test managed-bootstrap
swift run --package-path swift Parakey --self-test managed-runtime
"$HOME/Library/Application Support/SuperDictate/LocalModels/runtime-v2/bin/python3" -B scripts/test-local-asr.py
```

Python-тест требует numpy. Он проверяет манифесты, контрольные суммы, недокачанные
файлы, кеш, JSON-протокол и разбиение аудио, но не качество распознавания.
`managed-bootstrap` скачивает интерпретатор во временный каталог, проверяет запуск
без пользовательского PATH и повторное использование, затем удаляет каталог.
`managed-runtime` устанавливает общий движок и проверяет импорты всех движков.
`--self-test local-model-smoke` дополнительно скачивает Qwen 0.6B и шесть раз
распознаёт синтетическую русскую фразу. Веса остаются доступными в настройках,
но выбранная пользователем модель не меняется. Это не замена проверке качества
всех моделей на реальной речи и длительному профилированию памяти.

Повторяемая проверка ресурсов (требует уже установленную Qwen 0.6B):

```bash
"$HOME/Library/Application Support/SuperDictate/LocalModels/runtime-v2/bin/python3" -B scripts/check-local-asr-resources.py
```

На M1 Pro с 16 ГБ, 16 сентября 2026: 12 последовательных коротких синтетических
запросов, RSS процесса от 476,4 до 457,3 МиБ, разброс после трёх прогревочных
запросов 2,5 МиБ. Процесс завершился, временный каталог удалился. RSS не является
полной оценкой памяти GPU; этот короткий прогон не исключает утечек на длинных
записях или в остальных движках.

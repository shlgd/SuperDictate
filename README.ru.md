# SuperDictate

**Быстрая локальная диктовка для macOS.** Нажмите клавишу, говорите — и текст
появится в том приложении, где вы работаете. Аудио и расшифровка не покидают
ваш Mac: ни облачного API, ни аккаунтов, ни телеметрии.

## Зачем

- **Локальное распознавание.** Parakeet TDT v3 на Apple Neural Engine через
  CoreML. После однократной загрузки модели диктовка работает без интернета.
- **18 языков** или автоопределение — см. [Языки](#языки).
- **Быстро.** Нет обращения к сети, поэтому задержка ограничена вашим Mac, а не
  каналом связи.
- **Приватность по устройству.** Ни аналитики, ни аккаунтов, ни телеметрии.
  История и настройки лежат в вашей домашней папке.
- **Вставляет текст в любое приложение.** Текст попадает прямо в активное поле
  через Accessibility, а не в отдельное окно, откуда его надо копировать.
- **Бесплатно, лицензия MIT.**

## Требования

- Mac с Apple Silicon (`M1` или новее)
- macOS 14 или новее
- ~460 МБ на диске для модели (лучше иметь не менее 1 ГБ свободного места)
- Интернет только при первом запуске, для загрузки модели

Intel Mac, Windows и Linux не поддерживаются.

## Установить за минуту

1. Откройте приложение **Terminal**.
2. Вставьте эту команду и нажмите Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/shlgd/SuperDictate/v0.2.37/install.sh | /usr/bin/arch -arm64 /bin/bash
```

3. В открывшемся SuperDictate нажмите `Разрешить` для **Микрофона**,
   **Универсального доступа** и **Мониторинга ввода**.
4. Дождитесь статуса `Работает`, нажмите **правый Command** и говорите.
   Нажмите **правый Command** ещё раз, чтобы вставить текст.

При первом запуске один раз загрузится локальная модель распознавания. Xcode и
Command Line Tools для обычной установки не нужны.

Хотите прочитать скрипт перед запуском? Это [`install.sh`](install.sh) в этом
репозитории, а команда выше закреплена за тегом `v0.2.37`, поэтому её
содержимое не изменится задним числом. Что делает установщик — в разделе
[Что делает установщик](#что-делает-установщик).

## Языки

Выбирается в `Настройки → Язык диктовки`. По умолчанию `Автоопределение` — это
правильный выбор для большинства. Явный выбор языка смещает декодер к нужной
письменности (латиница или кириллица) и убирает редкие посторонние кириллические
символы, которые v3 иногда выдаёт на латинской речи.

| | | | |
|---|---|---|---|
| Автоопределение | Английский | Испанский | Французский |
| Немецкий | Итальянский | Португальский | Румынский |
| Польский | Чешский | Словацкий | Словенский |
| Хорватский | Боснийский | Русский | Украинский |
| Белорусский | Болгарский | Сербский | |

Язык интерфейса приложения (английский или русский) переключается независимо от
языка диктовки.

## Горячие клавиши

- **Правый Command** — начать диктовку. В режиме `Нажатие-переключатель` (по
  умолчанию) повторное нажатие завершает запись; в режиме `Нажать и держать`
  запись завершается отпусканием клавиши.
- **Правый Option + правый Command** — альтернативно завершить активную запись.
  Он выполняет противоположное действие: если основной хоткей нажимает Enter,
  этот завершит без Enter, и наоборот. Альтернативный хоткей можно выключить.
- **Правый Shift + правый Command** — открыть или закрыть быструю историю.

Все три сочетания можно изменить независимо. Поддерживаются одиночные клавиши,
функциональные клавиши, обычные сочетания и сочетания только из модификаторов,
например `Option + Command`. Левая и правая основные клавиши различаются:
сочетание с правым Command не сработает от левого Command.

Пока открыто окно записи нового сочетания, глобальная диктовка временно
приостанавливается. Нажатые клавиши только записывают новый хоткей и ничего не
запускают.

## Настройки

Откройте `SuperDictate` из Applications и нажмите кнопку-шестерёнку.

**Диктовка**

- `Режим запуска` — `Нажатие-переключатель` (по умолчанию) или
  `Нажать и держать`.
- `Поведение завершения` — вставить текст либо вставить текст и нажать Enter.
  Настраиваемая задержка перед Enter (по умолчанию 120 мс) помогает
  приложениям, которым нужно время, чтобы принять вставленный текст.
- `Язык диктовки` — автоопределение или один из 18 языков.
- `Устройство ввода` — выбрать конкретный микрофон вместо системного.
- `Приглушать звук во время записи` — включено по умолчанию.

**Обработка текста**

- `Пользовательские замены` — собственный список «найти/заменить», который
  применяется к расшифровке до вставки. Правильное решение для имён, жаргона,
  названий продуктов и всего, что модель стабильно слышит неверно. Замены можно
  синхронизировать из файла.
- `Удалять слова-паразиты` — выключено по умолчанию. Консервативный проход,
  который убирает отдельно стоящие `um`, `uh`, `ah`, `er`, `erm`, `hmm` (включая
  растянутые формы вроде `ummm`) и чинит оставшуюся пунктуацию и заглавные
  буквы. Неоднозначные слова вроде `like` и `you know` намеренно не трогаются.
  Ваши явные замены всегда важнее удаления паразитов.

**Индикатор записи**

Во время записи рядом с кареткой появляется небольшая капсула, анимация которой
следует за громкостью голоса — видно, что вас слышат.

- Показывать или скрывать волну
- Размер капсулы
- Цвет во время записи и во время расшифровки
- Стиль фона

**Прочее**

- Язык интерфейса (`RU / EN`) — применяется к обеим панелям мгновенно
- Звуки старта и завершения (включены по умолчанию)
- Показывать в Dock (по умолчанию выключено — приложение живёт в строке меню)
- Автоматическая проверка обновлений

Изменения сначала остаются черновиком; кнопка `Сохранить и перезапустить`
применяет их вместе и перезапускает только фоновую службу. История и модель при
этом не удаляются.

## Панель управления

Основная панель компактна: в ней видны состояние фоновой службы, недостающие
разрешения и доступное обновление. Кнопки управления службой находятся справа
от её статуса; при наведении macOS показывает пояснение к каждой кнопке.

Панель можно полностью закрыть. Отдельная фоновая служба продолжит работать и
автоматически запустится после следующего входа в macOS.

## Зачем нужны разрешения

macOS не разрешает приложению выдать их самому:

- **Microphone** — записывать голос во время активной диктовки.
- **Accessibility** — находить активное поле и вставлять готовый текст.
- **Input Monitoring** — видеть глобальную горячую клавишу.

Если после выдачи разрешений статус не стал `Ready`, откройте SuperDictate и
нажмите `Restart` у фоновой службы. Если приложение не появилось в системном
списке, нажмите `Try Again` у соответствующего разрешения.

## Обновление

**Если в SuperDictate уже есть кнопка `Обновить`** (v0.2.26 и новее): откройте
приложение из папки Applications и нажмите эту кнопку. Архив скачается, пройдёт
проверку SHA-256, bundle ID, версии и подписи, после чего приложение заменит
себя и откроется заново. История, настройки и модель сохраняются. Предыдущая
версия автоматически восстанавливается при ошибке.

**Если SuperDictate был установлен до появления кнопки обновления** (v0.2.25 и
старее): ничего не удаляйте. Один раз повторите установочную команду — она
заменяет только `/Applications/SuperDictate.app`, а история, настройки и уже
загруженная модель остаются на месте. Все следующие обновления можно будет
устанавливать кнопкой в панели.

```bash
curl -fsSL https://raw.githubusercontent.com/shlgd/SuperDictate/v0.2.37/install.sh | /usr/bin/arch -arm64 /bin/bash
```

Приложение само не устанавливает обновления в фоне: запуск обновления всегда
нужно подтвердить кнопкой.

Последнюю опубликованную версию всегда можно увидеть на странице
[GitHub Releases](https://github.com/shlgd/SuperDictate/releases/latest).

## Что делает установщик

1. Загружает `SuperDictate.zip` из
   [GitHub Releases](https://github.com/shlgd/SuperDictate/releases).
2. Проверяет закреплённую SHA-256, версию, bundle ID, архитектуру arm64,
   подпись и microphone-entitlements.
3. Безопасно заменяет `/Applications/SuperDictate.app` и открывает панель.

## Сборка из исходников

### Самый простой способ

Команда скачает открытый исходный код, соберёт его локально и установит
результат в `/Applications`:

```bash
curl -fsSL https://raw.githubusercontent.com/shlgd/SuperDictate/v0.2.37/install.sh | SUPERDICTATE_BUILD_FROM_SOURCE=1 /usr/bin/arch -arm64 /bin/bash
```

Понадобятся бесплатные Apple Command Line Tools. Если их нет, установщик
откроет стандартный диалог установки; после его завершения запустите команду
ещё раз. Первая чистая сборка обычно занимает несколько минут.

По умолчанию сборка из исходников скачивает точный коммит исходного кода
релиза и проверяет его через GitHub. Для разработки можно передать свои
`SUPERDICTATE_REF` и `SUPERDICTATE_SOURCE_COMMIT`; без совпадения коммита
установщик не запустит скачанный `scripts/build-app.sh`.

### Ручная сборка для разработки

```bash
xcode-select --install
git clone https://github.com/shlgd/SuperDictate.git
cd SuperDictate
swift run -c debug --package-path swift Parakey --self-test all
./scripts/build-app.sh ./dist/SuperDictate.app
open ./dist/SuperDictate.app
```

По умолчанию локальная сборка подписывается ad-hoc. Чтобы использовать свой
сертификат, передайте его имя:

```bash
SIGN_IDENTITY="Apple Development: Your Name (TEAMID)" ./scripts/build-app.sh ./dist/SuperDictate.app
```

Не перемещайте и не удаляйте `dist/SuperDictate.app`, пока фоновая служба
запущена из этой сборки. Для обычного использования предпочтительнее команда
с `SUPERDICTATE_BUILD_FROM_SOURCE=1`, которая ставит приложение в
`/Applications`.

## Проверки перед pull request

```bash
bash -n install.sh uninstall.sh scripts/build-app.sh
plutil -lint swift/Info.plist entitlements.plist
swift run -c debug --package-path swift Parakey --self-test all
./scripts/build-app.sh ./dist/SuperDictate.app
codesign --verify --deep --strict ./dist/SuperDictate.app
```

GitHub Actions повторяет самотесты, собирает bundle, прогоняет установщик на
чистом macOS runner и проверяет удаление.

См. [CONTRIBUTING.md](CONTRIBUTING.md).

## Ограничения

- Поддерживаются только Apple Silicon и macOS 14 или новее. Intel Mac,
  Windows и Linux пока не поддерживаются.
- Публичная сборка подписана ad-hoc и не нотарифицирована Apple. Установка
  через команду выше проверена, но ZIP, скачанный вручную через браузер, может
  вызвать предупреждение Gatekeeper.
- Из-за отсутствия стабильной Developer ID подписи macOS иногда повторно
  запрашивает разрешения после обновления. Нотаризация требует платного
  аккаунта Apple Developer.
- Первый запуск требует интернет для загрузки модели. Панель проверяет
  обновления при открытии; фоновая автопроверка, если включена, обращается к
  публичному GitHub API раз в шесть часов.
- Одна запись автоматически завершается через 20 минут. При аварийном
  завершении незаконченная запись сохраняется для восстановления истории.
- Защищённые поля паролей и приложения, которые скрывают Accessibility-данные,
  могут не отдавать координаты каретки. Это влияет на положение анимации, но
  не всегда мешает вставке текста.
- Ориентир по ресурсам на текущей сборке: около 460 МБ на диске для модели,
  примерно 100–150 МБ памяти в простое и до 500 МБ во время загрузки/работы
  модели. Значения зависят от macOS и длины записи.

## Данные и приватность

- История и настройки: `~/Library/Application Support/SuperDictate`
- Модель FluidAudio: `~/Library/Application Support/FluidAudio/Models`
- LaunchAgent: `~/Library/LaunchAgents/com.local.superdictate.agent.plist`
- Логи: `~/Library/Logs/SuperDictate*`
- Аналитики, аккаунтов и телеметрии нет.

Подробнее: [PRIVACY.md](PRIVACY.md). Об уязвимостях — [SECURITY.md](SECURITY.md).

## Удаление

```bash
curl -fsSL https://raw.githubusercontent.com/shlgd/SuperDictate/v0.2.37/uninstall.sh | bash
```

Приложение и фоновая служба удаляются. История, настройки и модель сохраняются,
чтобы случайно не потерять данные и не загружать модель повторно.
